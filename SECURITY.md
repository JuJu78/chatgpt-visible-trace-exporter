# Security Policy

## Principe

Ce bookmarklet s’exécute localement dans le navigateur et ne doit pas envoyer de données vers un serveur externe.

## Signaler un problème

Ouvrez une issue GitHub si vous identifiez :

- un comportement réseau inattendu ;
- une fuite possible d’information ;
- une incompatibilité navigateur ;
- un sélecteur devenu obsolète après changement de l’interface ChatGPT.

## Recommandation utilisateur

N’exécutez jamais un bookmarklet que vous n’avez pas lu ou dont vous ne comprenez pas le comportement général.
